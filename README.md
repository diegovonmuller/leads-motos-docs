# Qualificação de Leads — Rede de Motos

Plataforma de qualificação automática de leads via WhatsApp com consulta de CPF em tempo real.

## Stack
- Node.js + TypeScript
- Evolution API (WhatsApp Oficial Meta)
- BigDataCorp API (consulta CPF)
- PostgreSQL + Redis
- N8N (orquestrador)
- Claude API (IA)
- AWS (infraestrutura)

## Modelo de negócio
- R$950/loja/mês
- Meta API no cartão do cliente
- Meta: 300 lojas
